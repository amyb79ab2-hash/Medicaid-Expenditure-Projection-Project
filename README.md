# Medicaid-Expenditure-Projection-Project
This project analyzes historical Medicaid expenditure data and develops a forecasting model to estimate future Medicaid spending trends. The goal was to transform raw healthcare expenditure data into meaningful insights that can support planning and decision-making.
In addition to forecasting expenditures, the project incorporates New York State Medicaid enrollment data to answer several business questions related to Medicaid participation, per-enrollee spending, and the relationship between enrollment and expenditures.
## Key Questions
* How have Medicaid expenditures changed over time?
* What are the projected Medicaid expenditures for future years?
* How many people are enrolled in Medicaid in New York State?
* How much is spent per enrolled individual?
* Is there a relationship between Medicaid enrollment and per-person expenditure?
## Tools Used
* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
## Key Findings
* Medicaid expenditures have generally increased over time.
* New York Medicaid enrollment remained above six million individuals throughout the analysis period.
* Spending per enrollee provides additional insight beyond total expenditures alone.
* Enrollment and per-person spending do not always move together, suggesting that multiple factors influence Medicaid costs.
